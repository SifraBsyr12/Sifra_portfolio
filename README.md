# Sifra Basayar – Portfolio (React + Vite)

## Run locally
```
npm install
npm run dev
```
Open the address Vite prints (usually http://localhost:5173).

## Build for hosting
```
npm run build
```
Upload the `dist/` folder to Netlify, Vercel, or GitHub Pages.

## Edit content
All text lives in `src/data.js`. Colors are the variables at the top of `src/styles.css` (navy and gray).
